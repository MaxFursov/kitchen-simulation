# Обробка замовлень на кухні (варіант 8)

Лабораторна робота з багатопоточності в Java (предмет «Асинхронне програмування»).

## Завдання

Симулювати роботу кухні ресторану: кухарі (потоки) готують страви на замовлення клієнтів.
Одночасно можуть готуватись не більше **4** страв (плити контролює **семафор**).
Кухня має **робочі години** (10:00 – 16:00): до відкриття та після закриття замовлення
не приймаються і не готуються.

## Що показує програма

| Вимога | Де реалізовано |
|---|---|
| Потоки та інтерфейс `Runnable` | `Cook`, `Client`, `ThreadStateMonitor` реалізують `Runnable` |
| Семафор для контролю плит | `Kitchen.cook()` — `Semaphore(4, true)`, `acquire()` / `release()` у `finally` |
| Thread states | `ThreadStateMonitor` показує стани `NEW → RUNNABLE/WAITING/TIMED_WAITING → TERMINATED` |
| Робочі години | `Kitchen.isOpen()`, `placeOrder()`, `closeAndCancelPending()` |
| Обробка помилок | власний `KitchenClosedException`, `InterruptedException`, `UncaughtExceptionHandler`, `finally` |
| Зрозумілий вивід | `KitchenLog` — кожен рядок із часом і поясненням українською |

## Сценарій

- Кухня відчинена 10:00 – 16:00, 6 кухарів, 4 плити.
- 24 клієнти. Один приходить до відкриття (отримує відмову), двоє — після закриття (відмова).
- Перед закриттям (15:40 – 15:58) приходить черга: частину замовлень кухарі не встигають узяти в роботу — вони скасовуються.
- Час прискорений: 20 хвилин «кухонного» часу = 1 реальна секунда (уся програма працює ≈ 20 с).

## Структура

```
src/kitchen/
├── Main.java                 – запуск симуляції
├── Kitchen.java              – кухня: семафор плит, черга замовлень, робочі години
├── Cook.java                 – кухар (Runnable)
├── Client.java               – клієнт (Runnable)
├── Order.java                – замовлення (CountDownLatch для очікування клієнтом)
├── Dish.java                 – страва
├── ThreadStateMonitor.java   – вивід станів потоків (Thread.State)
├── SimClock.java             – прискорений віртуальний годинник
├── KitchenLog.java           – журнал подій
└── KitchenClosedException.java
```

## Запуск

Потрібна Java 11 або новіша.

```bash
javac -encoding UTF-8 -d out src/kitchen/*.java
java -cp out kitchen.Main
```
